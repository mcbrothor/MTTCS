# 투자관리 → MTN 통합

VMware와 Excel은 운영 의존성에서 제외했다. 계산은 TypeScript 엔진, 기존 MTN 공급자, Supabase 스냅샷으로 실행한다. `.xlsm`은 실행하거나 가져오지 않으며 CSV와 매크로 없는 `.xlsx`만 일회성 투자 아이디어 입력으로 허용한다.

## 제공 기능

- `/api/market-breadth`: 20·60·200일선 상회율과 60일 양수익 비율을 `20/35/25/20`으로 합성하고 지수 고점 대비 -10/-20 Breadth 다이버전스를 경고한다.
- `/api/investor-flow/oscillator`: 외국인·기관 순매수 비율, 연속성, 가속도, 가격-수급 다이버전스를 업종 단위로 합산한다.
- `/api/portfolio/allocation`: TIP 모멘텀 경계가 `> 0`일 때만 공격자산 상위 4개, 그 외에는 BIL을 이기는 방어자산 상위 3개 또는 BIL 100%를 제안한다. 자동 주문은 없다.
- Leader/Momentum 스캐너: 20일 거래량, 60일 거래대금 Z-score, 7일 갭 추세를 `50/30/20`으로 합성하고 Raw/SMA3/EMA5/EMA7을 제공한다.
- `/api/market-sentiment`: 252거래일 롤링 정규화를 사용한다. Put/Call, VKOSPI, 국채선물이 없으면 중립값을 넣지 않고 `BLOCKED`로 반환한다.
- Watchlist: 투자 논지, 촉매, 무효화 조건, 재검토일, 상태, 출처를 관리하고 CSV/XLSX를 일회성으로 가져온다.

모든 계산 결과에는 `asOf`, `provider`, `quality`, `modelVersion`, `warnings`가 포함된다. 스냅샷의 유니크 키에는 모델 버전과 기준일이 들어가 동일 결과의 중복 저장을 막는다.

## 레거시와 의도적으로 다른 점

- HAA 공격·방어 유니버스를 분리해 방어자산이 공격자산 순위에 섞이지 않는다.
- Fear & Greed는 전체 기간 MinMax 대신 과거 252거래일만 사용해 미래정보 편향을 제거한다.
- 옵션·국채 데이터가 빠진 심리 지표는 정상 신호로 보정하지 않는다.
- 투자 아이디어 파일은 원본 시스템이 아니며 가져오기 이후 MTN DB가 기준이다.
