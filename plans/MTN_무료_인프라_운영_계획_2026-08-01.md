# MTN 무료 인프라 운영 계획

기준일: 2026-08-01
목표: 월 고정비 0원 안에서 데이터 신선도와 투자 안전장치를 유지한다.

## 1. 확정 아키텍처

| 계층 | 무료 구성 | 책임 |
|---|---|---|
| Web/API | Vercel Hobby | Next.js UI, 인증 API, 일 1회 배치 |
| Database | Supabase Free | 원장, health, RLS, 멱등 저장 |
| Frequent scheduler | Supabase Cron | 공식 피드 30분, BLS 발표창 재시도 |
| Secret storage | Supabase Vault | 앱 origin과 cron bearer token 암호화 |
| News/macro | 공식 무료 원천 | Fed, BOK, SEC, BLS |
| AI | 무료 할당량 provider + local fallback | 분석 보조, 실패 시 deterministic 규칙 유지 |

유료 뉴스 피드, Vercel Pro Cron, 유료 Redis/Queue, 상시 VM은 사용하지 않는다.

## 2. 실행 주기와 무료 예산

- 공식 RSS: 30분 간격, 하루 48회 수집 작업
- BLS: 08:30 ET 발표를 포괄하는 UTC 12시·13시의 35/45/55분, 하루 6회
- Vercel 일일 배치: 각 경로 최대 하루 1회
- 사용자 온디맨드 수집: 인증 필수, 모든 피드 원천에 30분 쿨다운
- Supabase Cron 기록: 30일 보존 후 자동 삭제
- 시장 인텔리전스 원장: 동일 `(source, external_id, content_hash)`는 중복 저장하지 않음

## 3. 실패 정책

- 필수 원천 누락·최신 실패·SLA 초과 시 `BLOCKED`, 위험 배수 0
- 일부 수집 실패 시 `DEGRADED`; 마지막 정상값을 실시간 값으로 위장하지 않음
- AI 무료 할당량 소진 시 분석 방향을 생성하지 않고 공식 원천과 deterministic 위험 규칙만 표시
- Supabase Cron 실패 시 화면의 인증된 수동 갱신으로 복구하되 쿨다운은 우회하지 않음
- 투자 판단 자동 실행은 금지하고 `RESEARCH_ONLY`를 유지

## 4. 배포 순서

1. 스테이징에서 `20260731123727_market_intelligence_v1.sql` 적용
2. 기존 v1이 현재 스키마보다 오래된 경우 `20260801123027_repair_market_intelligence_remote_drift.sql` 적용
3. `20260801085212_free_infrastructure_scheduler.sql` 적용
4. Supabase Vault에 `mtn_app_base_url`, `mtn_cron_secret` 생성
5. Vercel `CRON_SECRET`과 Vault의 `mtn_cron_secret` 일치 확인
6. dry-run으로 Fed/BOK/SEC/BLS 성공 및 BLS 4개 지표 확인
7. 실제 feed/indicator 1회 실행 후 `/intelligence`의 source health 확인
8. `cron.job`, `cron.job_run_details`, `net._http_response`에서 첫 24시간 실패 점검

원격 적용 전에는 작업 트리의 다른 미적용 migration을 반드시 분리한다.

## 5. 운영 KPI

- 공식 RSS 관측 지연 p95: 45분 이하
- BLS 발표 관측: 공식 발표 후 15분 이하
- 중복 revision 저장: 0건
- required source가 stale인데 `READY`: 0건
- Supabase DB: 400 MB 이하 경보, 500 MB 도달 금지
- 유료 인프라 청구: 0원
- 자동 매매 연결: 0건

## 6. 무료 한계와 대응

- Vercel Hobby 일일 Cron은 실행 시각 정밀도가 낮으므로 발표 시각 민감 작업에 사용하지 않는다.
- Supabase Free 프로젝트가 중지되거나 할당량에 접근하면 신규 매매 판단을 `BLOCKED`로 유지한다.
- 범용 실시간 뉴스 스트림은 무료·합법적·안정적인 SLA를 보장하기 어렵다. 공식 원천 중심으로 운영하고 라이선스 뉴스는 유료 전환 승인 전까지 추가하지 않는다.
- 무료 AI provider 결과는 핵심 신호가 아니라 설명 보조로만 사용하며, 할당량 소진이 추천 안전장치를 약화시키지 않게 한다.
